# Composer ⊚

Every serious collector eventually has a question the search box can't hold:
*owned by a mutual, under half an ETH, warm palette, from a project I star.*
Composer is where that question gets built — visually, rule by rule — and
answered live against the whole catalog.

**How:** Open Global Search — the Composer is the special first row.

- **①&#xFE0E; The rules** — tappable chips: price bounds, project scope, palette and traits, owner social classes, your own lists.
- **②&#xFE0E; The Readout** — the query read back in plain English, so you always know what you actually asked.
- **③&#xFE0E; The live answer** — the catalog answers as you compose; no run button.
- **④&#xFE0E; Programs** — save the query and it keeps answering with live data whenever you return.

## Where it lives

Open **Global Search** — the Composer is the special first row. It runs on a
deliberately dark stage of its own, whatever colorway the app is wearing.

## Composing

A query is a stack of tappable rules: price bounds (◊), project scope, palette
and trait facets, **owner social classes** (yours ⚭, mutuals ⚯, followed ⚬,
strangers △ — and ⟁ **CARTEL**, wallets holding multiple pieces of the same
project), and **your own lists** (★ starred, ✛ wishlist, ◰ albums). Scope the
query to a single project and its full **trait vocabulary** (⨝) unlocks as
rules.

As you build, **the Readout** reads the query back in plain English — the
sentence *is* the query, so you always know exactly what you asked. The match
count pops with every rule, with the ±N bite each rule takes.

## The answer does things

Results are a real gallery, and the gallery acts:

- **Select** (❐) flips into bulk mode — **CART ALL**, **WISHLIST ALL**, or
  **ALBUM ALL** (your choice of a numbered snapshot frozen to this moment, or
  a live Program-backed album that keeps answering).
- **Link** (⧉) mints a share URL that opens the Composer onto the live query —
  send a question, not a screenshot.
- **Σ listed value** rides the live strip — what the whole answer would cost.

## Programs

Save a query as a **Program** and it keeps living: each Program wears **the
Spectrum** — the colour distribution of its current answer — so a saved
question visibly changes complexion as the market moves under it.

And when a query strangles itself to zero matches, **the Loosener** names the
rule doing the strangling — a tappable "frees N" pill — so a dead end is one
tap from alive.
