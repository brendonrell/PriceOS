# The App — Settings & Display

MY PD is the settings surface — but on PriceOS, display is a first-class feature, not a preferences afterthought. The interface is an instrument; this is where you tune it.

## Colorways

The colorway picker paints the entire app through one variable system:

| Pill | Colorway |
| --- | --- |
| ◩ | Custom — the per-page default: home wears the daily Mood Ring, Projects their artist's colour, profiles their owner's |
| ◻ | Light Mode |
| ◼ | Dark Mode |
| ▨ | Orange Mode |
| ⁂ | Hash Synesthesia — colour driven by chain data |
| B | Blueberry Mode |
| R | Cherry Mode |

A hidden **Haze Mode** lives behind the picker for the collectors who find it: your own hex, with animated variations (tint, drift, pulse, chromatic) and a dropper (◉) that samples any page's live colour. An explicit pick wins on every page; the Custom default keeps the per-page colours. These docs carry the same picker and default to Dark.

## Display modes

Lenses on the rendering itself — stackable, persistent, instant:

**Pure Light · Pure Dark · Anon · Zen · Sticker · Echo · Zero Context · Price Lens · Sentiment · ASCII-ID · Degen · Auto-Scroll · Price Logo**

Zen strips the interface to the art; Anon strips identity; Price Lens foregrounds every number; ASCII-ID swaps identity surfaces to their text-art form; Sticker Mode turns the app playful. Modes compose — a Zen + Price Lens session is a different app from a Sticker + Degen one, by design.

## Pings & rituals

The **MY PINGS** toggle bank controls what reaches you and how loudly ([Pings](/docs/pings/overview)), including night mode ⏾. Ritual modes go further — scheduled quiet (Silence, Cooling Pool) for collectors who want the platform to breathe with them.

## Workspaces

Saved arrangements of your working state, switchable from settings — the same collection, held differently for different jobs.

## One hard rule of the design

Everything meant to be read is **legible at full strength** — resting UI never hides behind decorative transparency. Fading carries meaning on PD (a completed To-Do, a disabled control) or it doesn't happen.
