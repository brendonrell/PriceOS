# The App — Settings & Display

MY PD is the settings surface — but on PriceOS, display is a first-class feature, not a preferences afterthought. The interface is an instrument; this is where you tune it. And the panel's title is itself a control: **triple-tap the MY PD header to open [the Spell Book](/docs/app/spell-book)**.

## Colorways

The colorway picker paints the entire app through one variable system:

| Pill | Colorway |
| --- | --- |
| ◩ | Custom — the per-page default: home wears the daily Mood Ring, Projects their artist's colour, profiles their owner's |
| ◻ | Light Mode |
| ◼ | Dark Mode |
| ▨ | Orange Mode |
| ⁂ | Hash Synesthesia — colour driven by chain data |
| B | Blueberry Mode |
| R | Cherry Mode |

A hidden **Haze Mode** lives behind the picker for the collectors who find it: your own hex, with animated variations (tint, drift, pulse, chromatic) and a dropper (◉) that samples any page's live colour. An explicit pick wins on every page; the Custom default keeps the per-page colours. These docs carry the same picker and default to Dark.

Beside it, **Profile Colorway** sets the colour *your* profile paints for every visitor — your page, your ink.

## Display modes — the two pill rows

Lenses on the rendering itself: stackable, persistent, instant, and each one toasts its new state as it flips.

**Row one — the big switches:**

| Pill | Mode | What it does |
| --- | --- | --- |
| PL | Pure Light | Locks the interface white-on-light, everywhere |
| PD | Pure Dark | The inverse lock |
| ‰ | Price Logo | The logo mark leads the interface |
| ○ | Anon Mode | Strips your own identity from your view |
| ⛶ | Zen Mode | Strips the interface down to the art |
| ⊞ | Sticker Mode | Hides [your stickers](/docs/stickers/the-binder-and-your-profile) — the collection keeps, the layer rests |
| ☼ | Ambient Strip | The late-night dimmer: pulls the whole interface to ember levels without moving a pixel of layout |

**Row two — the instruments:**

| Pill | Mode | What it does |
| --- | --- | --- |
| z | Zero Context | Removes explanatory context — the confident-collector setting |
| ◎ | Price Lens | Floor-relative pricing: every price reads against its floor |
| ◒ | Sentiment Weather | The crowd's mood as ambient weather |
| ⟁ | Cartel | You + your mutuals = the Cabal: project pages count how many of your mutuals also hold the work |
| ⍢ | ASCII-ID | Identity surfaces swap to their text-art form |
| ⇠ | Back Button | A persistent back arrow under the menu, for collectors who navigate that way |
| ⏥ | Menu Tape | Runs the tape treatment through the menu itself |
| ⍖ | Auto-Scroll | The interface browses for you |

Modes compose — a Zen + Price Lens session is a different app from a Sticker + Ambient one, by design.

## The Showcase pill

Cycles your profile Showcase's engine — Static ⑆ › Generative ⑇ › Gen Curated ⑈ › Artist ⑉ (the Artist face appears for whitelisted artists with a released Project). Detail in [Identity & Profiles](/docs/app/identity-and-profiles).

## Setup Codes

The **Setup Code** field encodes your entire PD configuration as a short shareable string — copy it (⧉), send it, paste any code and press Enter to wear someone else's whole setup. Codes round-trip losslessly, and they're the backbone of Workspaces below. (The [Sticker Manager](/docs/stickers/the-binder-and-your-profile) carries its own narrower code for just the sticker arrangement.)

## Workspaces

Workspaces are saved configurations you switch between with one tap — the same collection, held differently for different jobs. The shipped set is six working personas:

**Main · Zen · Appraiser · Trader · Curator · Scout**

— each a Setup Code under the hood (the Appraiser leads with Celestial and Price Lens; the Trader arms Price Lens, Panopticon, Offer Shield, Sentiment, and the Watch; the Scout hazes the room and watches everything). Creating your own workspace opens the naming sheet with the **Spaces** shelf — a library of mood presets (Observatory, Museum, The Village, Stargazer, Mission Control, and more) to start from, or start from exactly what you're wearing now.

## Pings & the Default Sort

- The **MY PINGS** bank — what reaches you and how loudly, pill by pill, including Silent Mode ⏾ — has [its own page](/docs/pings/controls).
- The **DEFAULT SORT** row sets the sort and the **grouping** (the ⁘ pill, cycling the full dimension order — see [Outputs](/docs/app/outputs)) that boot the app and re-apply on every project entry.

## One hard rule of the design

Everything meant to be read is **legible at full strength** — resting UI never hides behind decorative transparency. Fading carries meaning on PD (a completed To-Do, a disabled control, the Fog) or it doesn't happen.
